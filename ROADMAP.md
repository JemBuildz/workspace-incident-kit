# Roadmap

## Current: local HAR MVP

- Local HAR import and bundled synthetic sample
- Searchable, filterable request timeline
- Deterministic, evidence-linked failed/slow request findings
- Masked-by-default review for likely sensitive query values
- Markdown incident-report preview and export
- Synthetic fixtures and privacy-oriented tests

## Next

- Expand synthetic HAR edge-case coverage and redaction regression tests.
- Improve timing breakdowns and report clarity without claiming certainty the evidence cannot support.
- Add email-header analysis as an independent module.
- Add public DNS checks for common email configuration issues.

## Later, only if the privacy contract remains intact

- A command-line entry point for the deterministic core.
- More product log formats, each with documented limits and synthetic test fixtures.

No roadmap item is a current feature until implemented and documented in the README.
